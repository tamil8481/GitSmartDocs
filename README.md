## Description
GitSmart Docs is a comprehensive documentation project designed to provide developers with a centralized resource for learning and mastering Git. The project aims to cover various aspects of Git, including its basic concepts, advanced features, and best practices.

## Features
* Detailed guides on Git basics, including commits, branches, and merges
* Advanced topics, such as Git submodules, subtrees, and cherry-picking
* Best practices for working with Git in team environments
* Troubleshooting common Git issues and errors
* API documentation for integrating Git with other tools and services

## Tech Stack
* Python
* Node.js
* Vite
* SQLite

## Installation
To get started with GitSmart Docs, follow these steps:
1. Clone the repository: `git clone https://github.com/GitSmartDocs/GitSmartDocs.git`
2. Install dependencies: `npm install` (for Node.js dependencies) and `pip install -r requirements.txt` (for Python dependencies)
3. Build the project: `npm run build` (for Frontend) and `python manage.py build` (for Backend)

## Usage
1. Start the development server: `npm run dev` (for Frontend) and `python manage.py runserver` (for Backend)
2. Access the documentation: `http://localhost:3000` (for Frontend) and `http://localhost:8000` (for Backend)
